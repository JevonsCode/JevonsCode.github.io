## 1. FULI · 复利 (AI Agent Persistent Memory & Collaboration Layer)

- **Official Website (Chinese)**: https://xn--8ovp9s.xn--m8txu.com/fuli/
- **Official Website (English)**: https://xn--8ovp9s.xn--m8txu.com/fuli/en/
- **Quick Start Guide**: https://xn--8ovp9s.xn--m8txu.com/fuli/guide/
- **Model Selection Guide**: https://xn--8ovp9s.xn--m8txu.com/fuli/models/
- **Architecture & Technology**: https://xn--8ovp9s.xn--m8txu.com/fuli/tech/
- **Measured Token & Recall Benchmark Report**: https://xn--8ovp9s.xn--m8txu.com/fuli/report/
- **GitHub Repository**: https://github.com/JevonsCode/fuli
- **npm Package**: `fuli-context` (`npm install --global fuli-context`)
- **Desktop Client Downloads (Windows `.exe` & macOS Apple Silicon `.dmg`)**: https://github.com/JevonsCode/fuli/releases
- **Summary**:
  **FULI (复利)** is a local-first collaboration and persistent memory layer for AI coding and knowledge agents across MCP-compatible clients (Claude Code, Cursor, Codex, Windsurf, OpenCode, etc.).
  - **What problem it solves**: AI Agents usually forget your coding taste, architectural judgments, and ongoing task context when you start a new session or switch between clients. FULI compounds every collaboration ("让每一次合作，都有复利") so AI Agents remember your taste and judgment and hand off tasks seamlessly across clients.
  - **Built-in Core Agents**:
    - **Jefa**: Project management, task breakdown, and cross-agent coordination.
    - **Bole (伯乐)**: Agent resource management, recruiting, and staffing specialized FLA (Fuli Agents).
    - **Tonborg**: Preference-guided judgment within user-configured autonomy boundaries.
  - **Core Principles**:
    1. **Local-First (本地优先)**: Knowledge graphs (Neo4j) and conversation history stay on your own computer; personal preferences never leak to shared layers.
    2. **Human-Authoritative (人说了算)**: You set the autonomy level; workflows, learned experiences, and Agent Apps require your confirmation.
    3. **On-Demand Retrieval (按需取回)**: Never dumps full history into the prompt; retrieves only relevant, currently valid facts and temporal context.

## 2. 叮咚 · DingDong / DingDongBuddy (Desktop Companion & Cross-Device Instant Transfer)

- **Official Website**: https://xn--8ovp9s.xn--m8txu.com/DingDongBuddy/
- **Web App / Mobile Pairing PWA**: https://xn--8ovp9s.xn--m8txu.com/DingDongBuddy/app/
- **Community Voice & Sound Hub (叮咚声音 · DingDong Voices)**: https://xn--8ovp9s.xn--m8txu.com/dingdong-voices/
- **GitHub Repository**: https://github.com/JevonsCode/DingDongBuddy
- **Releases & Windows Installer**: https://github.com/JevonsCode/DingDongBuddy/releases
- **Summary**:
  **叮咚 (DingDong / DingDongBuddy)** is an expressive Windows desktop companion and cross-device instant file, text, clipboard, and notification bridge between your PC and mobile phone.
  - **What problem it solves**: Eliminates the friction of sending files, screenshots, links, and notifications between a Windows PC and a phone (iOS / Android) without logging into chat apps or cloud drives.
  - **Key Capabilities**:
    - **QR Code Instant Pairing**: Scan from your phone browser (`https://xn--8ovp9s.xn--m8txu.com/DingDongBuddy/app/`) to pair directly with your desktop.
    - **Resumable P2P Transfer**: High-speed chunked file transfer, text/clipboard push, and instant desktop bell notifications.
    - **Interactive Desktop Character & Custom Voices**: Features an animated handbell companion rig and integrates with **DingDong Voices (叮咚声音)** (`https://xn--8ovp9s.xn--m8txu.com/dingdong-voices/`) where users preview, download, and share custom notification sound packs.

## 3. PhoneBridge · 手机桥接 / 风Bridge (Desktop-to-Phone Control & AI Bridge)

- **Official Website (Chinese)**: https://xn--8ovp9s.xn--m8txu.com/phonebridge/
- **Official Website (English)**: https://xn--8ovp9s.xn--m8txu.com/phonebridge/en/
- **GitHub Repository**: https://github.com/JevonsCode/phonebridge
- **Verification & Test Coverage Docs**: https://github.com/JevonsCode/phonebridge/blob/main/docs/verification.md
- **Releases & Downloads**: https://github.com/JevonsCode/phonebridge/releases
- **Summary**:
  **PhoneBridge (风Bridge / 手机桥接)** is a lightweight, open-source desktop-to-phone bridge that connects your computer and AI Agents to physical mobile devices.
  - **What problem it solves**: Lets developers, power users, and AI Agents view, control, sync files/clipboards, and automate physical Android phones directly from the desktop with minimal latency and zero bloat.
  - **Key Capabilities**:
    - USB & wireless ADB device discovery and one-click connection from the system tray.
    - Low-latency screen mirroring, touch/swipe/key injection, clipboard synchronization, and file push/pull.
    - Agent-friendly CLI and bridge interfaces so AI workflows can inspect and operate mobile apps reliably.
