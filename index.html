1. FULI · 复利（让 AI Agent 记住你的品味与判断，跨客户端接力协作）

FULI 复利（npm: fuli-context）是本地优先（Local-First）的 AI Agent 持久记忆、品味判断与跨客户端接力协作层，支持 Claude Code、Cursor、Codex、Windsurf、OpenCode 等所有兼容 MCP 的 AI 客户端。内置项目统筹 Jefa、Agent 招聘伯乐 Bole 与偏好判断官 Tonborg，支持 FLA 自主沉淀 Workbench、Workflow 与 Agent App。所有知识图谱与会话记录均保存在用户本机。

2. 叮咚 · DingDong / DingDongBuddy（Windows 桌面 AI 伙伴与手机扫码跨设备闪电快传）

叮咚（DingDong / DingDongBuddy）是灵动有趣的 Windows 桌面伙伴与跨设备实时传输工具。手机无需注册登录，扫码打开 DingDong Web App 即可与电脑双向快传大文件（支持分片断点续传）、同步剪贴板文字与桌面摇铃提醒，并配有 叮咚声音（DingDong Voices） 社区语音包工坊。

3. PhoneBridge · 手机桥接 / 风Bridge（电脑控制与直连手机、AI Agent 手机自动化桥）

PhoneBridge（风Bridge / 手机桥接）是连接桌面电脑、AI Agent 与实体手机的轻量级开源桥接工具。支持系统托盘一键 USB / 无线连接 Android 手机，提供低延迟屏幕投屏控制、文件收发、剪贴板同步以及面向 AI Agent 的手机操作接口。
