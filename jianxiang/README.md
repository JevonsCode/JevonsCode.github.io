# 间象 · Jianxiang

图像与留白之间，自有想象。

[打开间象](https://xn--8ovp9s.xn--m8txu.com/jianxiang/) · [GitHub 源码](https://github.com/JevonsCode/JevonsCode.github.io/tree/master/jianxiang)

一个在浏览器中使用的图像创作工具，支持九宫格封面、长图、独立人物与文字图层，以及按格、按方向调整的溢出拼贴。

- 上传封面与多张图片，实时查看缩略图和文件名。
- 每个图层可独立移动、缩放、排序、隐藏或删除；更换背景会保留图层设置。
- 支持九格分别配置长图，逐张下载或按顺序导出 ZIP。
- 照片数量不再限制为每格 6 张。拖动排序手柄可重新排序，也可将照片移到封面的上方或下方。
- 手机长图编辑：单指上下浏览，双指移动、缩放选中照片；右下角固定预览入口。
- 下载旁可锁定编辑，防止误触；支持撤销、重做和步骤记录，本次打开保留最近 40 个状态。
- 草稿自动保存在本机，刷新或重新打开后恢复最近成功保存的作品。
- 拆图时计算格子间距，支持手动校准。
- 支持中文、English、Español 即时切换，切换时保留编辑内容，并在本机记住语言选择。
- 顶部「分享」分享当前网址；支持系统分享的设备会打开分享面板，否则复制链接。若浏览器限制剪贴板，也可手动复制。
- 可安装为 PWA；完成首次离线准备后，编辑、图层、三种语言和图片导出均可离线使用。

语言链接：在网址添加 `?lang=zh`、`?lang=en` 或 `?lang=es`。链接指定的语言优先于本机偏好。分享的是网站地址，照片与草稿仍留在当前浏览器中。

## 本地运行

无需安装依赖。在仓库目录运行：

```sh
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

## 安装与离线使用

首次联网打开页面，等待显示 **可离线使用**。离线包包含编辑器和全部默认素材，包括首次进入溢出模式时所需的人物、文字与背景。

- Android / 电脑：点击页面的 **安装应用**，或使用 Chrome / Edge 菜单里的安装选项。
- iPhone / iPad：在 Safari 打开，使用浏览器的 **分享 → 添加到主屏幕**；若出现“作为网页 App 打开”，请开启。
- 安装后从主屏幕启动，也可继续在浏览器里使用。作品和照片会自动保存到当前浏览器的 IndexedDB，重新打开时恢复最近成功保存的草稿；步骤记录仅保留在本次打开期间。

新版本完整下载后会提示更新，不会自动刷新编辑页面。导出当前作品并关闭其他间象页面后，可点击 **应用更新**；也可关闭应用，下一次打开时使用新版。

`sw.js` 仅缓存本应用目录的明确资源列表，不缓存上传照片、外部链接或站点其他项目。每次修改离线资源时，必须更新 `CACHE_VERSION`；新增运行时文件也必须加入 `SHELL_FILES`。离线安装按完整资源批次提交，下载失败时保留上一版。

## GitHub Pages

这是一个纯静态项目，`index.html` 和全部素材位于本目录。脚本和素材使用相对路径，兼容项目子目录与自定义域名。

线上地址为 **有点.意思.com/jianxiang/**，通过 `JevonsCode.github.io` 仓库的 `master` 分支发布。此目录无需单独的 `CNAME` 文件。

如需独立部署，将本目录内的文件复制到新仓库根目录，并在 **Settings → Pages** 中选择对应分支的 `/ (root)`。附带的 `.nojekyll` 可用于独立静态部署。

## 图片与数据

上传的图片只在设备上处理，不会上传到服务器。当前作品及图片资源自动保存在本机浏览器的 IndexedDB，刷新或重新打开后恢复最近成功保存的草稿。保存失败时会显示提示，并保留上一次成功保存的版本。

草稿不会在设备或浏览器之间同步。清除网站数据会删除本地草稿，隐私浏览模式也可能不保留数据；重要作品请导出备份。离线资源缓存与草稿存储相互独立。

长图保留各照片的画框比例，封面保持居中。超长图会按比例降低导出宽度以适应手机画布限制，保留全部照片和整体布局；实际分辨率可能低于所选宽度。

仓库中的默认封面与分层示例为本项目演示素材，人物、文字及补全背景经过图像编辑处理。

朋友圈预览按居中裁切模拟。微信客户端的实际裁切可能不同，建议先以“仅自己可见”试发。
