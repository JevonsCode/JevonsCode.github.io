# 间象 · Jianxiang

图像与留白之间，自有想象。

[打开间象](https://xn--8ovp9s.xn--m8txu.com/jianxiang/) · [GitHub 源码](https://github.com/JevonsCode/JevonsCode.github.io/tree/master/jianxiang)

一个在浏览器中使用的图像创作工具，支持九宫格封面、长图、独立人物与文字图层，以及按格、按方向调整的溢出拼贴。

- 上传封面与多张图片，实时查看缩略图和文件名。
- 每个图层可独立移动、缩放、排序、隐藏或删除；更换背景会保留图层设置。
- 支持九格分别配置长图，逐张下载或按顺序导出 ZIP。
- 手机长图编辑：单指上下浏览，双指移动、缩放选中照片。
- 拆图时计算格子间距，支持手动校准。
- 支持中文、English、Español 即时切换，切换时保留编辑内容，并在本机记住语言选择。
- 顶部「分享」分享当前网址；支持系统分享的设备会打开分享面板，否则复制链接。若浏览器限制剪贴板，也可手动复制。

语言链接：在网址添加 `?lang=zh`、`?lang=en` 或 `?lang=es`。链接指定的语言优先于本机偏好。分享的是网站地址，照片与草稿仍留在当前浏览器中。

## 本地运行

无需安装依赖。在仓库目录运行：

```sh
python3 -m http.server 4173
```

打开 <http://localhost:4173>。

## GitHub Pages

这是一个纯静态项目，`index.html` 和全部素材位于本目录。脚本和素材使用相对路径，兼容项目子目录与自定义域名。

线上地址为 **有点.意思.com/jianxiang/**，通过 `JevonsCode.github.io` 仓库的 `master` 分支发布。此目录无需单独的 `CNAME` 文件。

如需独立部署，将本目录内的文件复制到新仓库根目录，并在 **Settings → Pages** 中选择对应分支的 `/ (root)`。附带的 `.nojekyll` 可用于独立静态部署。

## 图片与数据

上传的图片只在当前浏览器内存中处理，不会上传到服务器。关闭或刷新网页会清空草稿，请先导出作品。
仓库中的默认封面与分层示例为本项目演示素材，人物、文字及补全背景经过图像编辑处理。

朋友圈预览按居中裁切模拟。微信客户端的实际裁切可能不同，建议先以“仅自己可见”试发。
